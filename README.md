# 🥬 VEGEPACK - Fresh Vegetable E-Commerce UI Demo

**VEGEPACK** is a comprehensive frontend prototype for a vegetable delivery platform. Built entirely with **HTML, CSS, and JavaScript**, this project demonstrates a complete user journey for a multi-role e-commerce system, designed specifically for UI/UX presentation and academic demonstration.

## 🚀 Project Overview

This repository contains a standalone web application that simulates the operations of a fresh vegetable business. It features a modern, responsive interface with interactive elements, mock data, and smooth transitions to showcase how the final system would function.

### 📂 Included Pages
1. **`index.html`** - Landing Page (Public view)
2. **`dashboard_pelanggan.html`** - Customer Dashboard (Shopping, Cart, Checkout, Tracking)
3. **`dashboard_admin.html`** - Admin Dashboard (Order & Product Management)
4. **`dashboard_owner.html`** - Owner Dashboard (Financial Reports & Analytics)
5. **`dashboard_kurir.html`** - Courier Dashboard (Delivery Management)

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Custom CSS, Flexbox, Grid, Glassmorphism), JavaScript (ES6+)
- **Data:** LocalStorage & Mock Data (JSON)
- **No Backend Required:** Runs entirely in the browser without a server.

## ⚙️ How to Run (Demo Mode)

Since this is a pure frontend demo, you do not need XAMPP or a database.

1. **Clone or Download** this repository.
2. Open the folder on your computer.
3. Double-click **`index.html`** to open it in your web browser (Chrome/Edge/Firefox recommended).
4. Navigate through the system using the "Login" button.

## ✨ Key Features Highlight

### 👤 Customer Experience
- **Interactive Catalog:** Filter products by category (Leafy, Fruit, Roots, etc.).
- **Shopping Cart:** Add items, adjust quantities, and see real-time total updates.
- **Checkout Flow:** Select payment methods (COD/QRIS simulation) and address input.
- **Order Tracking:** Visual timeline of order status.

### ⚙️ Admin & Owner Tools
- **Data Visualization:** CSS-based bar charts and donut charts for sales analytics.
- **Report Generation:** Simulated PDF export view for financial reports.
- **Stock Management:** Visual indicators for low stock alerts.

### 🚚 Courier Operations
- **Task List:** View assigned deliveries and update status (Accepted -> Delivered).
- **Commission Tracking:** View earnings based on completed deliveries.

##  Presentation Notes

- **Mock Data:** All products, orders, and financial data are hardcoded in JavaScript arrays to ensure the demo runs smoothly without internet or database connections.
- **Responsive Design:** The layout adapts to different screen sizes (Desktop/Tablet/Mobile).
- **Animations:** Includes smooth transitions, hover effects, and toast notifications for a polished user experience.
